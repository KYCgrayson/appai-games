# AppAI games

Static builds of the browser games shown on [appai.info](https://appai.info).
Source code lives in [KYCgrayson/APPAI](https://github.com/KYCgrayson/APPAI) under `games/`.

| Game | Play |
|---|---|
| River Crossing 過河謎題 | https://kycgrayson.github.io/appai-games/river-crossing/ |

All art and sound are generated in code. No network or AI calls during play.
Third-party code: [three.js](https://github.com/mrdoob/three.js) (MIT License, Copyright © 2010-2025 three.js authors).
